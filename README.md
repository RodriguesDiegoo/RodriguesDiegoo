## Sobre mim

Sou desenvolvedor Full Stack com experiência na criação de aplicações web, mobile, APIs, sistemas SaaS e integrações com serviços externos.

Atualmente, trabalho no desenvolvimento de produtos digitais utilizando principalmente **React**, **React Native**, **TypeScript**, **Node.js**, **C#/.NET**, **PostgreSQL** e **Docker**.

Meu objetivo é transformar ideias em aplicações modernas, escaláveis e fáceis de usar.
